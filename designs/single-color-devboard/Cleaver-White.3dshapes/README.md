# Cleaver White 3D models

Open `../Cleaver-White.kicad_pcb` in PCB Editor and press **Alt+3**. Enable
SMD, through-hole and unspecified models in the viewer's Appearance controls.
Press **F** to flip the board. If already open, reload the PCB from disk after
preserving any intentional unsaved work.

There are **594 model instances on 477 populated footprints**: 117 top MX
switches, 117 underside sockets, 117 reverse white LEDs, 117 diodes, 120
resistors, two capacitors, fuse, power switch, MOSFET and top dev-board assembly.
Probe pads, fiducials and mounting holes intentionally have no component model.
All paths are project-relative; no separate model library installation is needed.

## Sources and limits

- Switch/socket: KiSwitch, MIT. Standard passives/SOT packages: KiCad models,
  CC-BY-SA-4.0 with library exception. Bundled licenses and
  `inherited-sources.json` retain original URLs, revisions and modifications.
  The Kailh-shaped socket model is a **visual proxy** for the selected
  HanElectricity CPG151101S11-16; it is not HanElectricity vendor CAD. Compatibility
  checks use the HanElectricity drawing and actual pads/holes, not this model.
- YD-RP2040: reused CC0 approximate model from the original Cleaver project.
  Includes headers with assumed 2.54 mm carrier-to-module clearance, module PCB,
  USB shell, buttons and representative ICs. Actual module revision/header stack
  may differ. Generic switch appearance is not a specification of purchased keys.
- SOT-23: pinned KiCad source URL and hashes in `sources.json`.
- White LED: original CC0 simplified **BrtLed BL-HZ333H-L21-TRE** envelope,
  generated by `source/led_model.py` from the dimensions documented in
  `MECHANICAL.md`. Lens points into the aperture. This is **not vendor CAD**;
  terminal shape, marker, carrier thickness and solder stand-off are approximate.
  Total height is 1.10 mm; the 0.45 mm carrier / 0.65 mm lens split is approximate.
  VRML only for
  this model; no STEP counterpart is supplied for it.

No keycaps, plate, stabilizers or case are modeled. The models visualize assembly;
they do not qualify physical clearances or manufacturing tolerances.

## Reproduce

`python3 -B source/models_3d.py` applies models to the PCB and local footprints,
asserting that every non-model PCB byte is preserved. Normal board generation
also invokes it. `validation/models-3d.json` records model coverage and the
non-model PCB hash at attachment time. `check.py` subsequently resaves filled
copper; the final design hash is in `validation/validation.json`.

Previews: `../review/3d-top.png` and `../review/3d-bottom.png`, exported with
KiCad's actual raytracer. Example from the project directory:

```sh
kicad-cli pcb render --side bottom --width 2200 --height 1000 --zoom 2 --quality high --background opaque --output review/3d-bottom.png Cleaver-White.kicad_pcb
```
