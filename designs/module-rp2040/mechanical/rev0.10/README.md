# Mechanical revision 0.10

**A serviceable, lower-profile enclosure for the existing module-RP2040 rev0.9
PCB and switch plate.** This is a mechanical release, not an electronics revision.

- [Print files, hardware, assembly and qualification](case/README.md)
- [FreeCAD assembly](case/Cleaver-case-assembly-rev0.10.FCStd)
- [STEP assembly](case/Cleaver-case-assembly-rev0.10.step)
- [Case plan](case/case-plan.svg)
- [Height comparison](case/height-comparison.svg)
- [Fastener and badge sections](case/assembly-sections.svg)
- [CAD validation and artifact hashes](case/validation.json)

Use the **rev0.10 base and cover together** with the
[rev0.9 switch plate](../rev0.9/README.md). The eleven PCB mounting locations,
switch/stabilizer interfaces, 3.5 mm spacers, controller socket interface and
50.8 × 25.4 mm badge remain compatible with that PCB.
