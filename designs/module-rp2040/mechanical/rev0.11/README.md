# Revision 0.11 — removable PCB/plate cartridge

Use the **rev0.11 PCB, switch plate, base and cover together**. This revision
replaces the old eleven-hole stack with two independently positioned mounting
families and adds a replaceable, measurable USB-C bezel.

The 3° profile, bottom-fastened cosmetic cover, strengthened cover mounts and
gasket-retained badge carry forward from mechanical rev0.10. The eleven loose
PCB/plate spacers are replaced by integral downward plate bosses.
